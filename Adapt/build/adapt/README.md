The Adapt package: what a host project receives when Adapt is installed.
- shim/: the thin skill copied into <host>/.claude/skills/adapt/ (SKILL.md and host-side scripts).
- workspace/: the template the workspace <host>.adapt/ is created from (.claude tree, rules, folders).
- install/: init, tool fetching and upgrade.
What Adapt is: spec/adapt-spec.md. How it is built, in order: Adapt/build/BUILD-PLAN.md.
