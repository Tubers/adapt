RULE writing/fact-ownership - every fact is written down ONCE.
- State a fact in the document that OWNS it. Everywhere else write a pointer to that document.
- Never restate a finding for convenience. The copy that goes stale is always the one someone reads.
- A distilled summary can be staler than the document it summarises. Where the two disagree, the OWNER wins, always.
- Before writing a sentence, ask which layer owns it. If not the layer you are editing, write a pointer instead.
- Owners: a rule owns a fact that holds beyond one folder; a project's HISTORY.jsonl owns what happened; its TASKS.md owns what is next; a folder README owns only orientation.
