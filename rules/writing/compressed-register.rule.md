RULE writing/compressed-register - write this file in compressed register (caveman full).
- Applies to: handoffs, HISTORY.jsonl lines, and every rule file under rules/.
- full = drop articles, filler, pleasantries, hedging, tool narration, decorative tables, emoji. Sentence fragments are fine.
- NEVER drop negation (not, never, only, except), numbers, units, technical terms, code blocks, acronyms, or symbol, function or error names.
- Never invent abbreviations (cfg, impl). Never use the arrow character.
- NOT ultra, even though chat runs at ultra: ultra strips conjunctions and states each fact once, which destroys the WHY a written record exists to keep.
- Structural tables carry information; keep them. The ban is on ornament.
- Full prose instead for: documents written for a person, code and comments.
